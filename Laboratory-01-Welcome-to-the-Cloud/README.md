# Mission 1 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduces the basic responsibilities of a cloud infrastructure engineer through practical activities using a Linux cloud environment.

## Objectives

- Access a cloud-based Linux environment using KillerCoda.
- Explore the Linux operating system.
- Gather basic system information.
- Organize files and directories.
- Create and manage a GitHub repository.
- Document technical activities using Markdown.

## Activities Performed

1. Accessed Ubuntu 24.04 using KillerCoda.
2. Created a Linux user with Bash, home directory, and sudo privileges.
3. Logged in to the new user account.
4. Checked the username, working directory, and hostname.
5. Gathered Linux system information.
6. Created the required files and directories.
7. Prepared a Cloud Computing Portfolio on GitHub.
8. Captured screenshots as evidence.
