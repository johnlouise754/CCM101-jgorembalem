# Mission 3 Reflection

This laboratory activity helped me understand how AWS, Microsoft Azure, and Google Cloud Platform provide different services for cloud computing. Among the three platforms, AWS impressed me the most because it offers a wide range of services that can support different types of applications and organizations. I learned that a cloud platform is not selected simply because it is popular, but because its services match the needs of a particular organization.

AWS, Azure, and GCP have many similarities. All three provide computing, storage, networking, databases, identity management, security, and other cloud services. They also allow organizations to use scalable infrastructure without having to maintain all physical hardware themselves. However, each provider has different strengths and services that may make one more appropriate than another for a specific situation.

Business requirements have an important influence on cloud platform selection. For example, Azure can be a good choice for an organization that already depends heavily on Microsoft technologies. Google Cloud can be suitable for AI, machine learning, data analytics, and Kubernetes workloads. AWS can be a flexible option for organizations that need a broad range of services and scalable infrastructure.

Acting as a Cloud Solutions Consultant taught me that technical decisions should be based on the actual problems and requirements of a client. I learned to compare cloud services and consider factors such as scalability, existing technology, performance, and business needs before making a recommendation.

My GitHub Cloud Computing Portfolio has also improved after completing this mission. I added research about three major cloud providers, comparison tables, client recommendations, Linux investigation results, and supporting screenshots. This made my portfolio more organized and demonstrated my ability to document technical work using Markdown.
